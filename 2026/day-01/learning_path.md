                                                            #90-days Personal DevOps Learning Plan.
	Profile Summary-
•	Currently working as an Analyst Cloud Engineer on the OpenShift Platform.
•	Have 4.5 years of experience managing and handling OpenShift-based clusters.
•	Possess basic knowledge of Linux, Kubernetes, Docker, Terraform, and other core DevOps concepts.
•	Looking to strengthen skills further in DevOps practices and modern cloud technologies.

	Goals to be achieved in next 90 Days-
•	Get hands-on practice with different DevOps tools.
•	Build a solid understanding of core DevOps concepts.
•	Deploy an application using Kubernetes, Terraform, and a CI/CD pipeline.

	DevOps skills want to build-
•	Learn to troubleshoot Linux-based issues effectively.
•	Create and deploy applications using Kubernetes and Terraform.
•	Build and manage a successful CI/CD pipeline.

	Simple Weekly Plan (Mon–Fri)- [Each Day 2hrs]
•	Day 1 → Watch lecture recordings, revise class notes, and learn new concepts.
•	Day 2 → Practice hands-on exercises for those concepts.
•	Day 3 → Revise and troubleshoot small issues.
•	Day 4 → Build a small project or deployment using what you learned.
•	Day 5 → Review the whole week and note key takeaways.
•	Saturday–Sunday → Focus on live classes and learn new topics (Linux, Docker, Kubernetes, Terraform. 
 	30-Minute Study Routine (Exception Days)
•	10 min → Watch part of a lecture or revise class notes.
•	10 min → Do a small hands-on exercise (e.g., run a command, deploy a pod, write a short Terraform script).
•	10 min → Summarize what you learned and note any issues/questions.
